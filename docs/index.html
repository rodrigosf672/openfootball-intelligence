Analyze any match

Enter any public StatsBomb open-data match_id (browse them at statsbomb/open-data) to fetch and analyze it live, entirely in your browser. Leave blank and click Load to return to the default World Cup Final.

Local LLM (optional)

Runs entirely in your browser via WebGPU (no server, nothing sent anywhere). It only phrases the computed evidence above into natural language -- it is not allowed to add facts of its own. First use downloads a small model (a few hundred MB), which can take a while.

Source, methodology, and full match report: github.com/rodrigosf672/openfootball-intelligence. Event data © StatsBomb, provided free under the StatsBomb open-data terms.
